# Online Auction System

## About the Project

The Online Auction System is a MERN stack web application that allows users to participate in online auctions. Users can view auction items, place bids, and manage auction-related activities through the application.

## Technologies Used

- MongoDB
- Express.js
- React.js
- Node.js
- HTML
- CSS
- JavaScript
